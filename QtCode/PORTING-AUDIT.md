# Delphi -> Qt 功能对照

核对日期：2026-11-05。范围：源码静态对照，不读写真实游戏数据。

## 判定规则

- 已实现：能追踪到入口、数据修改及输出路径；不是运行验收结论。
- 部分：已有实现，但缺操作、状态同步或错误处理。
- 缺失：空函数、不可达入口或关键流程未接通。
- 不等价：存在与原版文件格式或操作语义不同的确定证据。
- 待专项核对：本轮未穷尽其格式、分支或专用规则，不作完成判断。
- 替代：用不同界面或结构提供同等用途，不要求恢复原版冗余实现。
- 用户要求不移植：明确排除在 Qt 移植范围外，不计为缺口。

本清单不是把窗口数量当成功能数量；不统计完成百分比。当前 11 组自测仅覆盖
地图、事件、PNG/ZIP、保存回滚等测试明确涉及的路径，不能覆盖以下所有项。

## 结论与后续顺序

当前不能宣布功能移植完成；不只是等待真实数据测试。

1. 先修 KDEF、PIC 格式与入口、GRP 回写和关键值关联四条阻断工作流。
2. 修 R/DB/GRP/W 的保存失败传播与安全提交，避免假成功或损坏原文件。
3. 补原版有效操作：字段批量修改、像素编辑、多帧编辑、PNG 参数、地图单层复制、W 图上移动。
4. 明确旧 IMZ、KDEF 专用规则和场景事件约定，完成剩余专项静态核对。
5. 用合成夹具和 UI 测试逐项销项；真实数据闭环按用户要求留到以后。

初次审计仅新增此文档；后续按用户要求移除了 Qt Lua／剧本导入功能并更新 T01/T02。
