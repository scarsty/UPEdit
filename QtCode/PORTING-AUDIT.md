# Delphi -> Qt 功能对照

核对日期：2026-11-05。范围：源码静态对照，不读写真实游戏数据。

最新验证：Debug/Release x64 均实际通过 80 组隔离合成数据回归。下方规则段的 77 组为此前基线；新增与扩展证据以各分类条目为准。

## 判定规则

- 已实现：能追踪到入口、数据修改及输出路径；不是运行验收结论。
- 部分：已有实现，但缺操作、状态同步或错误处理。
- 缺失：空函数、不可达入口或关键流程未接通。
- 不等价：存在与原版文件格式或操作语义不同的确定证据。
- 待专项核对：本轮未穷尽其格式、分支或专用规则，不作完成判断。
- 替代：用不同界面或结构提供同等用途，不要求恢复原版冗余实现。
- 用户要求不移植：明确排除在 Qt 移植范围外，不计为缺口。

本清单不是把窗口数量当成功能数量；不统计完成百分比。当前 Debug/Release x64 均构建成功并实际运行通过 77 组隔离临时数据自测；覆盖头像替换、未保存确认与批量导出事务、场景模块伴随事件原子导入及预览导出、全图 PNG/BMP 安全导出、场景标注与缩放、共享地图严格读取、战斗位置缩放交互及预览地图严格读取、普通图片 GRP 追加、KDEF 对话窗口、PNG 导入设置、COL 完整性与批量导出事务、PIC 元数据、文件导入导出和未保存流程、GRP 绘画/变换像素、批量偏移、分节边界及颜色持久化、真实 XLSX 运行库及完整 int64 往返、组合 W schema、R/W 原子导入导出和直接编辑、引用选择边界、帧编辑文件对话框、跨窗口精灵复制、旧二进制 IMZ、跨容器元数据、损坏图片拒绝、地图边界、目录及来源持久化、隔离 HKCU 关联登记与扩展 KDEF 制导。这些测试不能替代完整 UI 或真实存档验收。

## 原版入口反向复核

本次以 Delphi 实际事件绑定反查 Qt，而不是仅检查既有条目的实现状态。主窗口菜单已对照：编辑器配置合并到语言/编码，四个快捷标签复用既有编辑器；脚本按要求排除，公告、托盘与旧在线服务仍按替代边界处理。发现文件关联窗口只有函数、没有菜单连接，现已补齐并自动触发真实对话框后取消。

GRP 列表右键菜单反查发现原始记录复制/粘贴、末尾追加空槽、PNG 替换并转 RLE 三类遗漏，现已补齐。原始记录走系统剪贴板私有格式，保留图像字节和偏移，不经单图编辑器像素转换；无效载荷拒绝。已有合成用例扩展覆盖跨窗口 PNG 原始字节、截断载荷不修改、追加保留顺序、实际文件框转 RLE 后像素及保存重读。列表保存复用现有保存按钮，无需重复右键命令。

主窗口连续流程已自动验证关闭 MDI 后列表清空、重开及重复打开仅一个子窗、主窗口正常关闭；没有证据需要改动其生命周期实现。

KDEF 按钮反查新增发现“重排星号”和“导出全部对话”遗漏，现已补齐。重排先去星号，再按原版 UTF-16 字符计数插入，整倍数末尾也插入；0 表示仅去星号。宽度安全写回 KDEF/talkarrange，写失败不改文本。实际按钮测试覆盖宽度 2/0、其他配置保持、UTF-16LE BOM 导出全部记录、导出包含尚未保存的编辑且不改对话资源。事件文本导出已遍历全部事件，不需重复实现。

PNG 容器按钮/右键反查发现批量偏移、末尾追加/删除、设置总贴图数遗漏，现已补齐。批量支持 X/Y/双轴、赋值及加减乘除；反向范围归一化，除零或 int16 越界整批拒绝。数量缩减要求确认；旧 IMZ 连续编号、文件夹/ZIP 稀疏编号保持。新增测试覆盖五类运算、轴和范围隔离、失败原子性、数量取消及增减保留原编号。

本次还反查了 R/W、主地图、战场、场景、PIC、头像、PNG 导入及关联列表的按钮/右键命令；旧 Excel 路径合并为 XLSX，PIC 选择全部由默认全范围替代。鼠标/键盘事件、辅助子窗及专用制导的全部分支仍未穷尽，此段不是完整 UI 验收声明。当前回归合计 80 组，取代前述 77 组基线。
