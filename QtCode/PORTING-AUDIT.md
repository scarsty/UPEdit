## 大图场景扩展（2026-11-07）

### 几何遮挡标注（2026-11-08）

当前用户工作流只保留几何标注与 JSON。像素笔刷、深度读数、像素撤销及 `.sbg/.wbg` 项目入口已从界面移除；导入大图不再分配像素深度图。底图独立导入，原点与几何遮挡统一导出 JSON，不需要迁移旧成果。下文像素项目描述为历史实现记录，不再是当前操作方式。旧内部实现暂保留供既有回归使用，不作为用户入口。

场景与战场“大图与遮挡”接入参考 HTML 的几何标注面板：半透明多边形、墙根基准线与端点、树根基准点、对象列表、名称/类型/颜色/高度/根基准属性、可见与锁定、独立撤销重做、辅助等轴网格。墙体点击墙根 A、B，再向上移动点击确定高度；树木/屋檐逐点点击，右键闭合；选择工具点选轮廓，点选树根工具更新基准 Y，Esc 取消未完成轮廓。树木可通过类型选择改为屋檐；多边形不能直接切换成墙体，需重新标定墙根。模拟人物沿用原图块 2501。

轮廓、墙根和树根均使用大图像素坐标，辅助网格原点使用“大图内地图原点”。斜墙在人物脚底 X 处插值墙根 Y，树木/屋檐比较脚底与树根 Y；位于后方时仅裁剪人物图像落在多边形内的像素。“被挡人物透明度”默认 0（完全遮挡），可调为 0.3 等半透。多个区域重叠不会重复衰减透明度。该效果显示被挡人物，不是让已经烘焙在底图中的建筑消失；没有建筑后方的干净背景，无法还原真正的建筑淡出。

“导出标注 JSON”独立保存对象，不嵌入底图；兼容 HTML 2.0 的 `items/occlusionData` 字段，包含 wallBase、wallHeight、rootPivotY、polygon，并补充原点、地图绑定、可见/锁定及人物透明度。无绑定的 HTML JSON 可导入当前地图；本程序导出数据校验地图绑定。新数据先完整验证再替换，损坏/非法顶点/错误高度拒绝并保留当前标注；原子保存。几何 JSON 与像素 `.sbg/.wbg` 分开保存，后者不包含几何标注。切换地图或存档前提示未导出标注，已导出标注切换后需重新导入；导入底图/像素项目会清空旧几何标注并走放弃确认。

验证包含墙体三击构建、斜墙插值、多边形闭合、树根点选、实际精灵像素前后遮挡、半透明重叠、JSON 往返/损坏保护/HTML 字段兼容和轮廓显示像素。尚未完成用户真实地图的人工视觉验收。

场景编辑器新增“大图场景”面板。WebP/PNG/JPEG 静态合成图可替代原贴图层显示；原 S/D 数据仍提供地图坐标、海拔及事件。导入和涂绘遮挡不修改原地图或事件；普通场景保存仍保存原 S/D，大图与遮挡通过独立 `.sbg` 项目保存。

操作顺序：

1. 打开对应存档槽与场景，导入不含动态事件、人物的干净大图。
2. 按游戏坐标设置“大图内地图原点 X/Y”，默认 `(1152,18)`，表示地图 `(0,0)` 底点在图片内的位置，图片左上角为像素 `(0,0)`。可修改原点，不裁剪透明边界，也不再按图片尺寸猜测留边。旧项目转换为对应原点，保持原有对齐。当前不提供任意透视变换。
3. 选择“选择建筑落地点”，点击建筑对应的原地图格；也可输入落点 X/Y。
4. 选择“涂绘遮挡”，沿建筑可遮挡人物的轮廓涂绘；右键或“擦除遮挡”清除。支持笔刷半径、遮挡区域显示、独立撤销/重做。
5. 启用固定编号 2501 的预览人物，选择“移动预览人物”在地图上检查前后遮挡。人物跟随鼠标，使用原场景第 4 层的高度偏移；不改写高度，也不代表各游戏人物移动高度规则已验收。
6. 保存 `.sbg`；在相同存档槽、场景下打开可恢复大图、对齐偏移与像素深度。切换其他场景不会套用，关闭或替换未保存项目有放弃确认。

遮挡按原场景绘制顺序编码落点深度，深度较大的静态像素挡住后方动态精灵；同深度时动态精灵在前。未涂绘区域不遮挡。事件与预览人物按同一地图顺序绘制，动态事件本身仍从原事件层读取。项目内嵌无损 PNG 和小端 int32 深度数据，包含版本标记、存档槽、场景编号和尺寸，保存使用原子替换；拒绝截断、非法尺寸及深度，失败保留当前项目。

边界：仅支持不透明静态遮挡；半透明前景、多层桥梁及已烘焙进大图的动态事件无法由本模式自动恢复。大图最多 1600 万像素，遮挡撤销历史有内存预算；原有 Ctrl+Z/重做仍针对 S/D，遮挡使用独立按钮。当前只在编辑器中提供预览，游戏引擎必须另行实现 `.sbg` 读取及同样的深度比较。

验证覆盖：像素级前后遮挡、原地图高度和事件隔离、偏移画布事件与人物绘制、鼠标笔刷及撤销重做、项目往返、损坏文件拒绝、跨场景禁用。未使用用户真实 WebP 大图完成视觉验收。

### promise / pig3 / cpp 副本验证（2026-11-06）

### 地图编辑交互补充

主地图与战场侧栏支持分组折叠。鼠标红框按地面菱形中心取格，复制区域保留黄框；待粘贴内容以半透明贴图和绿色范围显示，右下角格为粘贴锚点，超出地图部分裁掉。场景模块预览同时读取模块携带的事件定义和高度，不将事件索引当作贴图编号。预览不调用实际粘贴或保存。

三种编辑器共用横向占满侧栏的折叠标题。各分组展开状态切换时保存至当前 INI 的 `[MapSections]`，下次打开恢复；Main、War、Scene 使用独立键，互不影响。未保存过的分组沿用默认展开状态。写入复用保留编码与原有配置的 INI 更新器，失败时状态栏提示。回归检查实际标题宽度、箭头与内容显隐、窗口重建恢复和 UTF-16 配置保护。

场景鼠标遮挡信息固定为像素、深度、落点三行；无遮挡时仍保留三行。战场可导入 WebP/PNG/JPEG 大图替代静态贴图，并独立保存 PNG；当前图像绑定当前地图编号，切换其他地图不套用，删除地图时更新绑定。主地图不提供大图功能。

战场大图支持像素遮挡编辑：选择建筑落地点后涂绘，右键或擦除工具清除；支持遮挡区域覆盖显示、笔刷半径、独立撤销/重做和固定 2501 人物跟随预览。人物逐像素使用与战场遍历一致的落点深度比较，同深度人物在前。鼠标遮挡读数固定三行。战场没有场景海拔层，不套用场景高度。

场景与战场均提供“大图内地图原点 X/Y”，默认 `(1152,18)`。编辑器实际绘制偏移为编辑器地图原点减去此设置，遮挡笔刷、像素读数和人物裁剪共用该变换。原点保存至独立大图项目；场景沿用旧格式的等价绘制偏移，战场 WBG2 显式保存原点并兼容 WBG1 的旧对齐。普通导入图片按当前设置对齐，不因图片尺寸自动改变原点。

使用“保存遮挡项目”将大图和深度一起保存为 `.wbg`，在相同地图编号下打开恢复。项目内含地图尺寸、无损 PNG 和小端 int32 深度，原子保存；截断、尺寸不符或地图编号不符时保留当前项目。替换、删除绑定地图及关闭窗口时对未保存遮挡确认。保存 PNG 只保存图像，不能保留遮挡。所有遮挡编辑均不写入 warfld 数据，游戏引擎读取和渲染支持仍需另行实现。

战场遮挡回归覆盖鼠标涂绘/右键擦除、撤销重做、人物前后遮挡像素、项目往返、损坏加载保护、跨地图隔离和原战场字节不变。尚未使用用户真实大图完成人工视觉验收。

新增隔离回归检查三类编辑器的实际预览像素及悬停不改数据、战场复制范围、大图对齐/跨地图隔离/无编辑标记导出，以及固定三行布局。自动像素检查不等同于用户真实大图视觉验收。

## 判定规则

- 已实现：能追踪到入口、数据修改及输出路径；不是运行验收结论。
- 部分：已有实现，但缺操作、状态同步或错误处理。
- 缺失：空函数、不可达入口或关键流程未接通。
- 不等价：存在与原版文件格式或操作语义不同的确定证据。
- 待专项核对：本轮未穷尽其格式、分支或专用规则，不作完成判断。
- 替代：用不同界面或结构提供同等用途，不要求恢复原版冗余实现。
- 用户要求不移植：明确排除在 Qt 移植范围外，不计为缺口。

## 实现与验收结论

E06–E08、W04、Z06–Z07、G07–G10 已补齐，实现和验证记录在所属分类表中。继续反查普通图片导入发现独立文件路径、区域编辑、GIF 全帧追加遗漏，现已补齐并覆盖自动测试。全部源码分支、完整兼容性及全部窗口验收仍未穷尽。

1. Debug/Release x64 构建及各 91 组隔离回归通过；四版完整资源验证均正常退出，适用检查 0 失败。跳过项不计为通过。
2. KDEF 全部指令、复杂 MOD schema、完整窗口操作组合、原生文件框与系统默认文件关联仍需专项验收，不能以已有局部测试替代。
3. 已提供真实资源的读取、临时目录保存及重读闭环已执行；promise/pig3 的 R 无损保存、cpp 0–4 槽数据库字段值及场景/事件修改保存均有证据。原资源未修改，副本和报告保留。
4. 游戏端载入执行、人工视觉对照、SQLite 附属对象、缺失存档和未提供格式仍未验收。场景 SMD + .events 与旧工具互换、旧 IMZ 元数据承载及 KDEF 无独立保存槽会话属于明确限制；pig3 批处理退出故障已隔离，不声称底层 Qt Windows 问题已修复。

按用户要求，Lua／剧本导入功能不列入 Qt 移植范围；T01/T02 保留为“不移植”。
当前结论：已复现的问题已修复或隔离并完成复测，但完整功能等价性、全部窗口交互和游戏端兼容尚未验收，不能将整个移植标为全部完成。
